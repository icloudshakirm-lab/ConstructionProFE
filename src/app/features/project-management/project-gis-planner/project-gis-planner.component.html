How to use

  1. Point — single click on the map.
  2. Line — click vertices, double-click to finish.
  3. Polygon — click vertices, double-click to close.
  4. Edit shapes — enable edit mode, then drag vertices.
  5. Delete — edit a shape, then use Delete.
  6. Export GeoJSON — logs to browser console (F12) and shows preview below the map.
