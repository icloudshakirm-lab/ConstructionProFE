How to use

  1. Point — single click on the map.
  2. Line style — pick color and thickness before drawing; each line keeps its style.
  3. Line — click vertices, double-click to finish. Segment lengths (m) appear on each segment.
  4. Labels — enter text, click Place on line, then click the target line.
  5. Polygon — same style, lengths on edges, and labels as lines.
  6. Edit shapes — enable edit mode, then drag vertices.
  7. Delete — edit a shape, then use Delete.
  8. Export GeoJSON — logs to browser console (F12) and shows preview below the map.
